# 민사소송법 복습 노트

9월 1일~10월 15일의 13차시를 정리한 학습 사이트입니다. 74개 주제, 판례 정리 131개 항목, 해설 퀴즈 222문항, 오답노트·북마크·메모·기록 백업을 제공합니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버로 실행할 수 있습니다. 별도 빌드나 서버 API는 필요하지 않습니다.

## GitHub Pages

저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다. 공개 페이지 주소는 `https://lawhlee.github.io/civilproc1/`입니다.

## 자료

`downloads/`에는 문맥교정 전사본과 상세 정리본 TXT가 있습니다. 교재 PDF·녹음 원본·개인 학습 기록은 포함하지 않습니다. 불명확한 발언은 전사 표시와 자료 안내를 참고하세요. 학습 노트의 교재 보충 설명, 교수의 견해, 판례의 결론은 구분했습니다.

## 판례 정리

`#/cases`에서 사건번호·쟁점으로 검색하고 주제·수업일·연결 근거를 함께 필터링할 수 있습니다. 각 항목은 사안, 쟁점, 판단, 답안과 복습 포인트, 구별해서 읽기, 강의 시각·교재 쪽수·공식 출처를 담고 있습니다. 관련 학습 노트에서도 판례로 이동할 수 있습니다.

- 강의 연결 49개: 전사·상세요약의 사례나 법리 설명을 교재와 대조하여 식별했습니다. 교수님이 사건번호를 직접 발언했다는 뜻은 아닙니다.
- 교재 보충 75개: 진도 내 같은 쟁점을 이해하는 데 필요한 판례입니다. 강의에서 해당 사건을 직접 다뤘다고 표시하지 않았습니다.
- 튜터링 기출 보충 7개: 2~4회차 기출 해설의 법리에 대응하여 추가한 판례입니다.
- 128개 항목은 공식 판결문·판례정보와 대조했고, 공식 원문을 확보하지 못한 3개는 교재 대조로 표시했습니다. 동일 사건이 여러 차시에 등장한 경우 강의 근거를 합쳤습니다. 병합 사건번호는 하나의 해설 항목으로 셉니다.
- 변경 전 판례, 반대·보충의견 및 교수·저자의 비판을 판례의 결론과 구별했습니다. 사건번호를 특정할 근거가 없는 가상사례는 판례 수에 포함하지 않았습니다.

전체 텍스트는 `downloads/cases-0901-1015.txt`에서 받을 수 있습니다. 목록의 **해설 모두 펼치기 → 인쇄 / PDF 저장**으로 현재 필터에 맞는 판례만 출력할 수도 있습니다. 정리 기준일은 2026-10-17입니다.

## 학습 기록 이동

기록은 각 사이트 주소의 브라우저 저장소에 보관됩니다. 기존 사이트의 **학습 기록 → 기록 내보내기**로 백업한 후, 이 사이트의 **백업 가져오기**에서 불러오면 됩니다. 주소가 바뀌어도 자동으로 옮겨지지는 않습니다.

## 구성

- `index.html`, `styles.css`, `app.js`, `core.js`, `course-data.js`, `icon.svg`: 정적 사이트
- `case-data.js`, `case-ui.js`: 판례 자료와 검색·열람 화면
- `downloads/`: 전체 통합 전사·정리, 10월 15일 전사·정리, 판례 전체 정리본
- `.nojekyll`: 정적 파일 게시 설정

## 튜터링 기출 연결

`#/cases?tutoring=past`에서 기출 연결 판례만 모아 볼 수 있으며 2·3·4회차별 필터도 제공합니다. 기출 13개 출제 묶음·19개 설문에 대한 대응표를 두고, 판례보다 조문·학설이 중심인 설문도 남겨 두었습니다.

기존 14개 판례에 문항 근거를 붙이고 7개를 추가하여, 기출과 연결되는 판례는 총 21개 항목입니다. 연도·문항·튜터링 PDF 쪽수·출제 쟁점·교정 메모를 확인할 수 있습니다. 기출 연결만의 정리본은 `downloads/cases-tutoring-past.txt`입니다.

튜터링은 학생 커뮤니티의 복기 내용을 일부 변형한 자료입니다. 기출 문제·해설에는 사건번호가 직접 기재되어 있지 않으므로, 판례 연결은 해설과 공식 판결의 법리 대응에 따른 학습용 연결입니다. 특정 판례가 실제 출제의 원형이었다는 표시가 아닙니다. 안내문에서 직접 언급한 97마1632도 기출 해설의 직접 인용과 구별했습니다. 예상문제 연결은 별도 표시하며 기출 필터·19설문 집계에 포함하지 않습니다.

과거 추심소송 법리와 변경 후 판례, 국내 관할과 국제재판관할, 표시정정과 피고경정, 미성년 원고·피고의 차이를 교정·보충했습니다. 기존 학습 노트 74개와 퀴즈 222문항 및 학습 기록 저장 방식은 유지됩니다.
